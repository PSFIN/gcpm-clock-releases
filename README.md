# GCPM Clock — desktop app downloads

Installers for the GCPM Clock time-tracking app (Gulf Coast Property Management). Download the latest from **Releases**:

- **Windows:** `GCPM-Clock-Setup.exe`
- **Mac with Apple chip (M1–M4):** `GCPM-Clock-Mac-AppleChip.dmg`
- **Mac with Intel chip:** `GCPM-Clock-Mac-Intel.dmg`

Sign in with your GCPM Microsoft work account; an administrator must have added you first. The app updates itself (Windows) or tells you when a new version is ready (Mac).

The first time you open it: on a Mac, right-click the app and choose **Open**; on Windows, click **More info → Run anyway**.
